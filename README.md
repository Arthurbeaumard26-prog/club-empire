# 🏆 Club Empire

Jeu de gestion de club de football dans le navigateur : Deviens légende.

## Jouer
Site officiel : https://club-empire.js.org (en cours d'activation)

## Nouveautés v1.0
- 💬 Messagerie 100% IA (Pollinations) : président, adjoint, capitaine, star, médecin, salle de presse et vos joueurs
- 🎙️ Conférence de presse après match (+3 moral)
- 💼 Négociation avec les agents du mercato (bonus d'acceptation des offres)
- 👤 Comptes manager locaux + chaîne WhatsApp d'actualité

Base de données réelle : 184 pays, 4582 clubs, 320 ligues.
